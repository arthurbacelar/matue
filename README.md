# Matuê — Fã-clube

Site estático de fã-clube independente, feito com HTML, CSS e JavaScript puro.

## Como visualizar

Abra `index.html` diretamente no navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `style.css`: identidade visual e estilos responsivos.
- `script.js`: menu para telas pequenas, ano do rodapé e galeria ampliada.
- `matue.jpg`, `matue2.jpg`, `matue3.jpg`, `matue4.jpg`: imagens usadas no site.

Fã-clube independente e não oficial, sem vínculo com o artista.
